## Короткий brief

Заголовок: «КПД производства квадрокоптеров».

Задача: отделить структуру цеха от потока данных и одним взглядом показать:

- пять параллельных рядов: «Сборка 1 / Сборка 2 / Сборка 3 / Пайка / ОТК»;
- поток событий: «QR-сканирование → Проверка операции → Расчёт → Отчёт»;
- компактную генеалогию: «QR деталей → QR узла / WIP → QR изделия»;
- три компонента: «План / Качество / Производительность» без чисел, весов и итоговой формулы;
- дорожную карту: «1. Методика / 2. Основа системы / 3. Учёт смен / 4. Расчёт КПД / 5. Отчёты / 6. Пилот»;
- подпись «План MVP · нормы задаются заводом».

Визуальный стиль: направление `system / Champ vivant gouverné` — управляемая модульная сетка, ясная инженерная геометрия, высокий контраст, ограниченная синяя палитра, минимум текста, без брендинга и случайных логотипов.

## Provenance

1. 2026-10-25 Infographic Artist `generate_brand_directions` получил актуальный контекст производства квадрокоптеров и подготовил три направления. Эти результаты были только арт-дирекцией и промптами, не изображениями. Все предложенные workflow-проверки имели статус `non_testé`.
2. Выбрано системное направление, потому что оно лучше разделяет параллельные ряды, последовательный поток событий, генеалогию и дорожную карту.
3. Изображение создано отдельным нативным `image_gen` в режиме `infographic-diagram`; CLI/API fallback и сторонний провайдер не использовались.
4. Исходный нативный файл сохранён средой генерации. Копия для проекта помещена в `docs/assets/kpd-production-quadcopters.png`; исходник не удалён.
5. Запрошенный ориентир был 2048×1152 px, однако нативный инструмент вернул 1672×941 px. Файл не масштабировался и не выдаётся за точный экспорт 2048×1152.

## Ограничения и следующий контроль

- Перед публикацией проверить изображение в реальном портфолио-контейнере на целевых ширинах, включая примерно 1280 px.
- Если нужен строгий файл 2048×1152, создать отдельный нативный вариант/экспорт, не выдавая простое растяжение за новый детализированный рендер.
- До использования QR-мотивов в рабочей среде проверить их декодером либо заменить гарантированно абстрактными маркерами.
- После стабилизации методики можно обновить инфографику, но не добавлять реальные нормы или результаты без разрешения владельца данных.
